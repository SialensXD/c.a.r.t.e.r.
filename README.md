# AI-Ассистент - Telegram Bot с Groq

AI-ассистент - это умный Telegram-бот, который автоматически отвечает на сообщения в личных сообщениях, когда вы занят. Интегрирован с Groq для использования быстрых и бесплатных AI-моделей.

## 🎯 Возможности

- 🤖 **AI-ответы** - Умные ответы через Groq (Llama 3.1, Qwen и др.)
- 🔴 **Режим занятости** - Включите/выключите автоматические ответы одной командой
- 💬 **Контекст диалога** - Помнит историю разговора для естественного общения
- 🆓 **Бесплатно** - Использует бесплатные модели Groq с высоким лимитом запросов
- 📊 **Статистика** - Отслеживание аптайма и активности

## 🚀 Быстрый старт

### 1. Получите API ключ Groq

1. Зарегистрируйтесь на [console.groq.com](https://console.groq.com/)
2. Получите бесплатный API ключ
3. Выберите модель (рекомендую `llama-3.1-8b-instant` - бесплатная и быстрая)

### 2. Создайте Telegram бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Скопируйте полученный токен

### 3. Локальная настройка

```powershell
# Создайте виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Установите зависимости
pip install -r requirements.txt

# Настройте переменные окружения
# Скопируйте .env.example в .env и заполните его
```

### 4. Настройте .env файл

```env
BOT_TOKEN=ваш_токен_от_BotFather
GROQ_API_KEY=ваш_ключ_от_Groq
GROQ_MODEL=llama-3.1-8b-instant
OWNER_NAME=Ваше_Имя
OWNER_USER_ID=ваш_telegram_id
```

### 5. Запустите бота

```powershell
python bot.py
```

## 📋 Команды бота

### Для всех пользователей:
- `/start` - Начать работу с ботом
- `/help` - Справка по командам
- `/status` - Статус бота

### Для владельца:
- `/busy` - Включить режим занятости (AI отвечает вместо вас)
- `/available` - Выключить режим занятости (вы отвечаете сами)
- `/reset` - Сбросить историю диалогов

## 🌐 Настройка для Render

### Переменные окружения:
- `BOT_TOKEN` - Токен вашего Telegram бота
- `GROQ_API_KEY` - API ключ от Groq
- `GROQ_MODEL` - Модель AI (например: `llama-3.1-8b-instant`)
- `OWNER_NAME` - Ваше имя для контекста AI
- `OWNER_USER_ID` - Ваш Telegram ID
- `DATABASE_URL` - (опционально) PostgreSQL для хранения истории
- `RENDER_EXTERNAL_URL` - URL вашего Render сервиса
- `WEBHOOK_SECRET` - Секретный ключ для webhook

### Настройки Render:
- **Среда выполнения:** Python
- **Команда сборки:** `pip install -r requirements.txt`
- **Команда запуска:** `python bot.py`
- **Путь проверки работоспособности:** `/health`

## 🧠 Как работает AI

1. Когда вы включаете режим занятости (`/busy`), бот начинает перехватывать сообщения
2. Каждое сообщение отправляется в Groq API
3. AI генерирует ответ на основе:
   - Системного промпта (настроен под вас)
   - Истории диалога (последние 10 сообщений)
   - Контекста вашего имени и ситуации
4. Ответ отправляется пользователю от имени бота

## 🔧 Опциональная база данных

Если хотите хранить историю диалогов:

1. Создайте PostgreSQL базу данных (можно использовать Supabase)
2. Добавьте `DATABASE_URL` в переменные окружения
3. Бот автоматически создаст таблицу `users` при первом запуске

## 🛠️ Структура проекта

- `bot.py` - Основной файл бота с обработкой сообщений
- `ai_handler.py` - Интеграция с Groq API
- `config.py` - Конфигурация из переменных окружения
- `handlers/user.py` - Базовые команды бота
- `requirements.txt` - Зависимости Python

## 🆓 Бесплатные модели Groq

Рекомендуемые бесплатные модели:
- `llama-3.1-8b-instant` - Самая быстрая, 14,400 запросов/день
- `llama-3.3-70b-versatile` - Более качественная, 1,000 запросов/день
- `qwen/qwen3-32b` - Сбалансированная, 60 RPM, хорошая многоязычность

## ⚠️ Важные замечания

- AI не идеален - проверяйте важные ответы
- История диалога хранится в памяти (ограничена 20 сообщениями)
- Бесплатные модели Groq имеют лимиты запросов (30 RPM для большинства моделей)
- Для работы 24/7 нужен облачный сервер (Render, Heroku и т.д.)
